# flake-pilot-copr

Fedora COPR build specification for [OSInside/flake-pilot](https://github.com/OSInside/flake-pilot).

This repository tracks the upstream project and automatically triggers COPR builds via Renovate. 
No modifications are made to the upstream source.

* **Upstream Project:** https://github.com/OSInside/flake-pilot
* **COPR Repository:** https://copr.fedorainfracloud.org/coprs/mmicene/flake-pilot/
